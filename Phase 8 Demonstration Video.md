# Phase 8: Demonstration Video - LegalEase

## 1. Demonstration Sequence
1. Display the LegalEase front page.
2. Introduce the project name and team.
3. Explain the purpose.
4. Explain use and benefits.
5. Show the VS Code project structure.
6. Start the FastAPI backend.
7. Start the Streamlit frontend.
8. Open the LegalEase interface in the browser.
9. Enter sample document details.
10. Click Generate Document.
11. Show the generated draft/preview.
12. Demonstrate document output if available.
13. Conclude with the final output and project benefits.

## 2. Voice-Over Points
* **Project Name**: LegalEase – AI-Powered Legal Document Generator.
* **Purpose**: Simplify structured first-draft preparation.
* **Benefits**: Faster drafting, consistent structure, simple interface and document output.
* **Working**: Streamlit sends the user input to FastAPI; FastAPI invokes Gemini; the generated draft is returned to the frontend.
* **Final Output**: A structured AI-assisted legal-document draft.
